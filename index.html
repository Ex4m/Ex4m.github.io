      Projects

      Side projects from the last four years. The early ones were written by hand in 2022 and early 2023, before AI coding assistants were part of everyday work, and they are where most of my Python fundamentals come from.

      Trading and DeFi

      Systems that read the market and act on it. Both current bots run on Solana as multithreaded, asynchronous Python applications working with live data streams. Strategy details stay private.

      LPDeltaShield

      CurrentCloud, 24/7Python, asyncio, Solana

      My most recent bot. It manages concentrated liquidity positions and works to limit their exposure to price moves, deciding when a position should be adjusted and when to leave it alone.

      It runs autonomously 24/7 on a cloud Linux server, where it moved from an on-premise machine. Next to the trading logic, the project covers deployment and stable unattended operation.

      The logic is private, so there is no public source.

      Stable CLMM bot

      ActivePython, Solana

      A liquidity provision bot for the USDC/USDT stablecoin pair. It manages a concentrated liquidity (CLMM) position, and because both tokens are stablecoins, the price risk is much lower than with volatile pairs. Written entirely in Python. The "Liquidity range bot" mode in the chart at the top of the page shows the general principle.

      LLM decision bots

      Python, OpenAI and Claude APIs

      Bots that pass live indicator data and market context to a language model, get a structured decision back and execute it automatically.

      Allrounder trading bot

      Hand-written, 2022Python, Pine Script, Gmail

      A scalping strategy for 5 to 15 minute charts, written in Pine Script on TradingView. Signals arrive by e-mail; the Python engine parses them, places a limit order, leaves it in the order book while the price is good and re-prices it when the market moves. The "Limit order bot" mode at the top of the page is this loop.

      Source on GitHub Strategy on TradingView

      Web page scoring bot for Telegram

      Python, AI API, Telegram

      Uses an AI API to score web pages and posts the results to a Telegram channel.
